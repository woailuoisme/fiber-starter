# 分类标签

这些技能基于 5 个标准分类角色进行沟通。此文件将这些角色映射到本仓库问题追踪器中所使用的实际标签。

| mattpocock/skills 中的标签 | 我们的追踪器中的标签 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此问题                      |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                    |
| `ready-for-agent`          | `ready-for-agent`    | 需求已完全明确，智能体可以直接开始处理    |
| `ready-for-human`          | `ready-for-human`    | 需要人类开发者参与实现                    |
| `wontfix`                  | `wontfix`            | 不予处理                                 |

当技能提及某状态角色（例如“应用智能体就绪 triage 标签”）时，使用此表对应的右侧标签值。

您可以直接编辑右侧列的文本，以匹配您实际使用的标签系统。
